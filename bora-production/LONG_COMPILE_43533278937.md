## 원시 파일 검증

검증 WAV 4개. 독립 RIFF 파서로 파일 SHA256, FLOAT PCM SHA256, 24kHz·샘플 수·실제 길이를 다시 확인했다. 각 문장별 원본/컴파일 PCM 바이트와 반환 토큰열의 일치 여부는 independent-verification.json에 있다.

이 수치는 두 공개 조각의 순수 합성과 컴파일 준비시간이다. 공통 다운로드·모델 로드·파일 저장·전사 검수시간은 합계에서 제외했다. 전체 강의나 303강의 완료시간을 예측하지 않는다. 실제 강의 원고·기존 27개 통과 조각·31개 차단 조각·운영 renderer·검수 기준은 변경하지 않았다.

상태: complete_public_diagnostics_no_promotion. 재합성 0회, 운영 결과 승격 0회다.

small은 운영과 동일한 1스레드·단어시각 ON·FLOAT32 polyphase 16kHz 배열 입력이다. Turbo는 기존 강화 진단과 동일한 4스레드·단어시각 OFF·WAV/PyAV 입력이다. 모델·설정·전처리를 함께 비교한 진단이며, 모델만 바꾼 효과나 ASR 속도 개선 실험으로 해석하지 않는다.

정답 원고를 ASR 프롬프트로 주지 않았다. 발음 정규화 후 결과는 별도 진단이며 기존 문자 오류 0·필수어 검수 기준이나 운영 상태를 바꾸지 않는다. 큰 전사 모델의 일치도만으로 실제 음성의 정확성을 확정하지 않는다.
