# 김보라 원본 CPU 반복 합성 실측

기준일: 2026-11-13 (한국시간)

**공개 두 문장에서는 준비비용을 포함해 합성시간이 줄었다. 8개씩 합성한 측정 지점에서 초기 비용을 회수했다.**

| 측정 | 원본 | 컴파일 | 시간 감소율 |
|---|---:|---:|---:|
| 예열 후 교차 반복 8개씩 | 373.308초 | 333.164초 | 10.75% |
| 첫 합성·컴파일 준비 포함 10개씩 | 464.189초 | 451.605초 | 2.71% |

시간 감소율이 음수이면 해당 범위에서 더 느렸다는 뜻이다. 준비비용 포함 관측 절약시간은 12.584초다.

두 공개 문장을 seed 5192·5193으로 반복해 총 20회 합성했다. 같은 모델과 컴파일 함수를 메모리에 유지했고, 기준 원본 2회→첫 컴파일 2회→실행 순서를 바꾼 반복 비교 16회 순서로 실행했다. 매 호출 뒤 원시 FLOAT WAV와 측정값을 저장했다.

시험문장:

1. 오늘 배운 내용을 잠깐 덮고, 자기 말로 한 번 설명해 보세요.
2. 지금은 조금 느려도 괜찮습니다. 한 문장씩 차분하게 읽어 보세요.

이번 CPU는 AMD EPYC 9V45이고, 앞선 12회 시험은 AMD EPYC 9V74였다. 두 실행의 시간을 합치거나 감소율을 합산하지 않았다.

## 음성 및 실행 검증

- 결과 20개 모두 기준 원본과 FLOAT PCM 바이트, 샘플 수, 24,000Hz 표본율, 반환된 전체 talker 토큰열이 정확히 같았다. 원본 반복 결과도 포함한다.
- 각 WAV 파일과 실제 PCM 데이터의 SHA256을 독립 RIFF 파서로 다시 계산해 기록과 일치함을 확인했다.
- 모든 합성은 자연 종료했고 신호 유효성 검사를 통과했다. 예열 후 컴파일 호출에서는 새 그래프가 생기지 않았다.
- 원래 모델 `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`, revision `0c0e3051f131929182e2c023b9537f8b1c68adfe`, Sohee, Korean, FP32와 기존 설명용 지시문·공식 샘플링을 유지했다.
- 기존 검사와 새 검사를 합한 11개 검사를 로컬과 실행기에서 통과했다. 모델·컴파일 객체를 한 번 생성하고 재사용하는 동작, 출력 불일치·재컴파일·실제 실행 누락·부분 결과의 성능 주장 차단을 검사했다.

## 측정 범위

합성시간에는 첫 컴파일과 컴파일 wrapper 준비비용을 포함했다. 공통 모델 다운로드·로드, 파일 저장, 출력 검증, 전사 검수시간은 이 합계에서 제외했다. 별도로 기록한 모델 로드는 1.365초다. 이는 강의 제작 전체 파이프라인의 전후 시간 측정이 아니다.

공개 설명문 두 개만 시험했다. 긴 강의·숫자·조문, 다른 CPU와 전체 303강의 속도·품질로 확대하지 않는다. 사람의 청취 검수나 새 ASR 검수는 수행하지 않았다. 전체 강의 제작시간을 예측하지 않았고 측정 범위 밖의 손익분기점을 추정하지 않았다. 운영 강의, 제작 활성화 요청, 원래 renderer와 검수 기준은 변경하지 않았다.
