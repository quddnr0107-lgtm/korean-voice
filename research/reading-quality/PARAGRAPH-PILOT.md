# 통합방위법 김보라: 문단 단위 시범 준비

2026-11-12. 이번 변경은 비공개 원고를 받아 합성 단위와 시간표를 준비하는 도구다.
운영 서버, 인증, 기존 음원, R2 재고·업로드·삭제를 변경하지 않는다.

## 확인한 운영 화면과 소스

- 운영 사이트 강의 화면에서 통합방위법 25강과 로그인 후 하루 1편 무료 안내를 확인했다.
- 현재 브라우저는 로그아웃 상태다. 원고 접근 전에 이용약관·개인정보처리방침 동의와 로그인이 필요하며, 임의로 동의하지 않았다.
- 따라서 실제 TB-001 원고 취득, 김보라 합성, 실물 R2 재고 확인, 사이트 음성 교체는 아직 하지 않았다.
- `_deploy/app.js`의 `renderExplain()`은 통합강의의 `examPrep` 본문을 **한 줄바꿈 이상**으로 나누어 `<p>`를 만든다. 빈 줄만 기준으로 합성하면 화면 문단을 넘을 수 있다.
- `_ttsActivateGroup()`은 현재 문장의 `<p>`를 추적하고, `_lecHighlightAtChar()`는 현재 문장 한 줄을 강조한다. 문단 단위 합성만으로 문장별 타이밍 검증을 대신할 수 없다.

## 도구

`paragraph_plan.py`는 네트워크·키·로그인 상태를 다루지 않는다.

```sh
python3 research/reading-quality/paragraph_plan.py private-input.json private-plan.json --lesson-id TB-001
```

입력은 인증된 강의 응답의 `lectureScript` 문자열 또는 그 문자열을 담은 JSON이다.
출력은 비공개 원고를 포함하므로 공개 저장소에 커밋하지 않는다. 기존 출력 파일은 덮어쓰지 않으며, 생성 파일 권한은 0600이다.

- 화면과 같은 한 줄바꿈 기준의 문단 경계를 유지한다. 원문의 빈 줄·공백·CRLF를 보존한다.
- 원문 UTF-16 위치와 읽기용 텍스트를 구분한다. 이모지 등 비-BMP 글자도 위치가 어긋나지 않게 계산한다.
- 긴 문단은 그 문단 내부의 문장/어절 경계에서만 나눈다. 나눌 적절한 경계가 없으면 글자를 강제로 자르는 대신 검토 표시를 남긴다.
- 검토된 조문 인용의 `[start_utf16,end_utf16]` 목록을 `--reading-spans`로 받을 수 있다. 문단을 넘는 인용 범위는 거부한다. `법`이라는 단어가 들어갔다고 자동으로 조문 낭독 모드로 바꾸지 않는다.
- 원문과 조각의 연속 범위·해시를 확인한다. 기존 원고를 줄이거나 덧붙이는 방식으로 맞추지 않는다.

```sh
python3 research/reading-quality/paragraph_plan.py private-plan.json private-timing.json --measurements private-final-pcm.json
```

시간표는 최종 연결에 사용할 PCM의 샘플 수·샘플레이트·조각 앞 간격을 입력받는다.
측정 파일은 전체 원문 해시와 단위별 원문 해시·ID가 일치해야 한다.
글자 수 추정 시간, 이전 원고의 측정값, 누락·중복 단위, 서로 다른 샘플레이트를 거부한다.

이 시간표는 사이트 입력용 준비 자료다. 실제 인코딩·배포 묶음의 샘플 정렬과 문장별 세부 정렬, 현재 줄 강조·클릭·이어듣기 검증은 실제 원고와 음성을 확보한 뒤 수행해야 한다. 아직 그 기능까지 통합했다고 주장하지 않는다.

## 검증

```sh
python3 -m unittest discover -s research/reading-quality -p test_paragraph_plan.py
```

독립적인 합성 원고로 16개 검사: 한 줄 문단, CRLF/공백 보존, UTF-16 이모지 위치, 조문 모드 경계, 문단 넘김 거부, 긴 문단 내부 분할, 끊을 수 없는 장문 검토, 원문 번호 보존, 실제 샘플·간격 계산, 낡은/중복/누락/추정/불일치 시간표와 변조된 글자 위치·원문 조각 거부.

실제 강의 청취 검사나 실제 R2 확인을 수행한 건수로 이 테스트 수를 계산하지 않는다.

## 이어서 실행할 순서

1. 동일 브라우저에서 사용자가 약관을 검토하고 로그인한다.
2. TB-001 원고와 화면 문단을 대조해 비공개 입력을 준비한다.
3. 승인한 김보라 설명 설정과 또박 낭독 설정을 실제 조각에 연결하고 후보를 합성·인식·비교한다.
4. 최종 PCM 기준 시간표 및 문장 정렬을 만들어 실제 강조·클릭·이어듣기를 검증한다.
5. 실제 저장 위치·R2 대상과 인증 경로를 확인한 후 시범 음원을 연결한다. 기존 음원 삭제는 별도 사용자 지시 이후에만 한다.
