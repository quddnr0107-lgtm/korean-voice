# 김보라 낭독 품질 연구·회귀 자료

2026-11-12. 범위: 법령 낭독에서 관찰된 오류의 재발 방지.
모든 인간 음성의 경우를 망라한 학습이나 모델 가중치 훈련이 아니다.
원문 텍스트, 낭독용 표현, 생성 음성, 인식 결과, 청취 평가는 구분한다.

## 관찰 기록

| 관찰 | 처리 및 한계 |
|---|---|
| 공·사 단체를 공, 사 단체로 끊음 | 기업체/단체 앞 공·사만 공사로 치환. 다른 가운뎃점은 보존하고 검토 표시 |
| 2호·4호 번호가 잘 들리지 않음 | 맨앞 목록 번호를 제N호로 명시. 실제 음성 번호는 별도 확인 |
| 자격을 가진 사람으로서 → 자격으로 서…처럼 들림 | 사용자 제보. 문장 전체 재합성. 인식 결과로 누락 점검하되 인식 오류 가능성을 유지 |
| 중간에 과도하게 들뜸, 차분한 지시가 불친절하게 들림 | 정답 파라미터 없음. 사용자 묘사를 단일 감정 지시로 과도하게 해석하지 않음 |
| 긴 모음과 웃음이 기계적 | 법령 원문에 웃음·기침·헐떡임 등을 임의로 삽입하지 않음 |
| 낮은 temperature/greedy가 음성 길이를 늘리며 반복 | 이 환경의 실제 생성 관찰. 보편 법칙으로 확대하지 않음. 길이 제한 도달/반복 시 검토 |

## 재현 가능한 검사

`python3 research/reading-quality/quality.py --test`

9,999개 번호 × 표기 3종 × 어휘 문맥 4종 = **119,988개** 텍스트 조합.
기대 숫자 읽기는 생성 함수와 다른 자리수 기반 오라클로 대조한다.
원문 보존, 변환 결과, 멱등성을 검사하고 코퍼스 해시를 저장한다.
소수·줄바꿈·동그라미 번호·공·사 예외의 회귀 6건과 인식 대조 5건을 추가한다.
이는 제한된 조합 공간의 전수 검사이며 모든 한국어 문장이나 실제 음성의 전수 검사가 아니다.
실제 합성/청취 건수는 test-result.json에 0으로 명시한다.

낭독 준비: `python3 research/reading-quality/quality.py --source source.txt`

인식 대조: `python3 research/reading-quality/quality.py --source source.txt --recognized asr.txt`

불일치 시 종료 코드 2와 차이 목록을 출력한다. 인식기에는 예상 원문을 힌트로 주지 않는다.
숫자 정규화가 맞더라도 발음이 보장되지 않는다. 출력에 남은 숫자·가운뎃점은 검토 대상이다.
이 도구는 독립 연구 모듈이며 기존 서비스나 자동 생성 작업에 아직 연결하지 않았다.

## 실제 음성 평가 절차

1. 원문 해시, 모델/리비전, 생성 설정, seed, 낭독문, 파일 해시를 기록한다.
2. 전체 음성을 독립 인식하고 원문과 대조한다. 의미 누락·반복·번호·법령명 불일치가 있으면 보류한다.
3. 원문과 다른 표기는 인식 오류인지 합성 오류인지 해당 구간을 들어 구분한다. 인식 일치만으로 승인하지 않는다.
4. 문장 경계와 조사 연결, 숫자의 자음, 긴 모음, 문장 끝 음정, 구간별 화자/감정 일관성은 청취 항목이다.
5. 클리핑, 긴 무음, 생성 한도 도달, 비정상 길이는 경보로 취급한다. 자연스러움의 자동 판정 기준으로 오용하지 않는다.
6. 오류 구간만 문장 단위로 재합성하고 앞뒤 연결을 다시 확인한다. 원본은 보존한다.

호흡·웃음·기침·목메임·헐떡임은 콘텐츠 의도와 화자 연기에 따라 필요한 경우에만 실험한다.
이를 많이 넣는다고 인간다운 음성이 되는 것은 아니다. 임의의 비언어 소리를 학습 데이터라고 주장하지 않는다.
한국어 연음·비음화·경음화 등을 모두 글자 치환하면 오히려 발음을 왜곡할 수 있으므로 이 모듈은 강제 치환하지 않는다.

## 추가 실험 설계 (미실행)

번호/조항/법령명/장문/열거/숫자 단위/고유명사/외래어/동음어/비언어 소리의 층화 표본을 준비한다.
같은 문장·seed 조건에서 생성 설정 하나씩 비교하고, 익명 A/B 청취로 명료성·자연스러움·피로감을 평가한다.
검증된 동의·라이선스가 있는 녹음만 훈련 후보로 삼는다. 상업 서비스 출력이나 특정인의 목소리를 무단 학습하지 않는다.
전수 음성 합성, 외부 유료 호출, 새 학습 실행은 이번 작업에서 하지 않았다.
