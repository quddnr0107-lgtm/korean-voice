# 김보라 음성: 논문 조사 및 추론 실험

2026-11-12. 세계의 모든 논문을 읽었다는 주장이 아니다. 아래 6편의 1차 원문에서
방법·평가·현재 모델과의 호환성을 확인했다. 검색 중 발견했으나 원문을 확인하지
못한 품질 지표 논문은 근거 목록에서 제외했다. 논문을 읽는 것과 모델 재훈련은 다르다.

## 근거와 적용 범위

| 원문 | 읽은 핵심 | 이 환경에서 한 일 / 하지 않은 일 |
|---|---|---|
| [Qwen3-TTS Technical Report](https://arxiv.org/html/2601.15621v1), §3.3, Table 1 | 1.7B CustomVoice는 지시 제어를 지원. 0.6B CustomVoice는 같은 제어를 지원하지 않음 | 이미 설치된 1.7B/Sohee로 간결한 문단 단위 지시를 사용. 비스트리밍은 기존에도 기본값이므로 신규 개선이라고 계산하지 않음 |
| [Taming Long-form TTS](https://arxiv.org/html/2609.16989v1), §2–3 | 다중 seed + 외부 ASR로 후보 선택하는 선행 방식과 비용 한계. LACI는 내부 attention 감시/rollback/임시 mask 사용 | 후보 2개 생성·독립 ASR CER 선택을 구현하고 실제 파일로 실행. LACI 내부 attention 제어는 구현하지 않음. 단순 재합성을 LACI라고 부르지 않음 |
| [Long-Context Speech Synthesis with Context-Aware Memory](https://arxiv.org/html/2508.14713v1), §1–2 | 개별 문장 연결의 문맥/화자/속도 불일치, 학습된 CAM 메모리 제안 | 기존과 동일한 의미 문단을 유지하는 실험 설계에 참고. Qwen에 CAM 모듈이나 기억을 추가했다는 주장은 하지 않음 |
| [StyleTTS2](https://arxiv.org/html/2306.07691v2), Appendix B.3 | 문장별 독립 스타일의 불일치와 고정 스타일의 단조로움. 이전/현재 스타일 벡터 보간 | 스타일을 하나의 감정 단어로 고정하지 않는 설계에 참고. Qwen CustomVoice API에는 해당 스타일 벡터가 없으므로 보간 미구현. 파형 crossfade는 스타일 보간이 아님 |
| [F5-TTS](https://arxiv.org/html/2410.06885v1), §3/5 | Flow-matching 모델의 Sway sampling | 현재 Qwen 12Hz의 AR 생성과 구조가 다르므로 미적용. temperature 조절을 Sway sampling이라고 부르지 않음 |
| [Seed-TTS](https://arxiv.org/html/2406.02430v1), §3–4 | 객관 지표와 주관 평가, preference/RL, 화자와 표현 제어 | 내용 정확도와 청취 선호를 분리해 기록. 자체 RL·fine-tuning을 수행하지 않음 |

원문 검색은 한국어/다국어 TTS, 운율, 장문 안정성, 추론 오류, 스타일 제어,
품질 평가를 대상으로 했다. 각 논문의 영어·중국어/특정 벤치마크 성능을 한국어
김보라 성능으로 그대로 옮겨 주장하지 않는다.

## 실제 적용한 파이프라인

1. 같은 강의 도입 문단, 같은 1.7B/Sohee, 같은 sampling 설정으로 seed 5192/7319 생성.
2. 예상 원문이나 initial_prompt를 주지 않은 Whisper-small 한국어 전체 인식.
3. 숫자·기호를 같은 평가 표기로 정규화한 후 Levenshtein 문자 오류율(CER) 계산.
4. 클리핑/긴 에너지 무음 검토 표시, 중요 어구 누락, CER 순서로 후보를 비교.
5. 에너지 무음·대략적 F0 중앙값/IQR·길이를 함께 기록하되 자연스러움 점수로 쓰지 않음.
6. 청취 승인은 별도. 인식 오류가 합성 오류일 수도, ASR 오류일 수도 있다.

`candidate_eval.py`가 3–5를 구현하고 `experiment.py`는 로컬 모델만 사용하는
bounded 1–4 seed 생성→인식→선택 파이프라인이다. 이 실험은 2 seed를 사용했다.
네트워크 namespace 격리와 telemetry 비활성화를 요구한다.
원문과 인식 텍스트는 개인 작업 폴더에 두며 공개 저장소에 강의 본문/음성을 넣지 않는다.

이번 비교에서는 기존 도입 파일도 같은 인식기로 평가했다. 기존 파일은 선택 후보에서
제외하고, 동일 대본의 신규 두 후보 중 선택했다. 따라서 기존보다 CER가 나쁠 수 있다.
불리한 결과도 그대로 기록하고, 청취하지 않은 상태에서 더 인간답다고 선언하지 않는다.

## 비용·범위·다음 검증

후보 선택은 추론 횟수에 비례해 비용이 늘어난다. 2개 후보 실험을 대규모 강의 전체에
무조건 확대하지 않는다. 먼저 대표적인 숫자/장문/전문 용어 표본으로 오류율과
실제 청취 선호를 확인해야 한다. 작은 한 문단 결과는 통계적 일반화 근거가 아니다.
오류가 적어도 리듬/정서가 더 좋다는 뜻은 아니다. F0가 넓다고 인간다운 것도 아니다.

현재 이 코드는 연구 브랜치에 저장된 실행 도구다. 기존 서비스 자동생성/배포 경로는
수정하지 않았다. 기존 119,988건은 텍스트 회귀 테스트이며 새로 12만 음성을
합성했다고 계산하지 않는다. 사용자 선호 자료를 모델 가중치에 학습시키지도 않았다.
