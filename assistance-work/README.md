# 보조설명 작성 중간 저장

공개 법령 원문에 붙일 보조설명의 작성 초고입니다. 각 sourceId는 원문의 법령·회차·위계·조문·문장·발생순서에 고정됩니다. 비공개 문제·정답 데이터는 포함하지 않습니다.

`reviewStatus: draft`는 내용 검토 전입니다. 초고의 개수는 정확성이나 배포 완료를 뜻하지 않습니다. 실제 원문·참조 조문·표와 대조한 별도 검토를 마쳐야 F1 음성 제작과 서비스 반영 대상으로 사용할 수 있습니다. `notes`의 미해결 근거 및 표시 오류는 승인 차단 사유입니다.

표 설명은 coverage의 원문 인덱스와 표 앵커를 명시합니다. 숫자·단위·예외·의무·재량을 별도 확인하며, 숨김 OCR 조각은 표시되는 표 전체와 함께 검토합니다.
