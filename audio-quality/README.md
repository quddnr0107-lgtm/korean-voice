# 김보라 ③ 음성 연결·구절 속도 검수

## 유지할 조건

사용자가 선택한 ③은 Qwen3-TTS 1.7B CustomVoice Sohee, Python FP32, CPU 4 threads다. 선택한 음색을 바꾸는 모델 교체, 전체 강의 속도 일괄 변경, 원고 의미 변경은 이 국소 수정에 포함하지 않는다. 원본 합성물은 재사용하고 문제가 확인된 부분만 처리한다.

## 2026-11-12 공개 법령 샘플에서 확인한 문제

전체 127.45초 중 사용자 지적은 약 58초였다. 문단 3은 56.22초에 시작한다. 문단 사이 실제 저에너지 여백은 약 0.485초이며, 다른 경계 0.435초와 0.515초 사이에 있어 유독 짧지 않았다.

문단 3 도입은 다음 패턴이었다. 아래 경계는 5ms RMS 기반 근사이며, 청취 평가는 아니다.

- ‘다음은’: 약 0.925초.
- 쉼: 약 0.685초.
- ‘누가 무엇을 지니는지입니다’: 약 2.010초.
- 쉼: 약 1.255초.

따라서 문단 사이의 무음을 일괄 늘리는 것보다 빠른 연속 구절에 기존 긴 쉼의 일부를 배분했다. 최초 rubberband 후보는 구절 RMS가 약 2.23dB 낮아져 채택하지 않았다. 최종 atempo=0.88 후보는 core RMS 변화가 약 +0.106dB였다.

## 구현

`repair_bora_transition.py`는 이 샘플의 SHA-256과 문단 시작 시점을 확인한 뒤 전역 57.67–60.37초의 고정 창만 교체한다. 문단 상대 1.63–3.80초의 연속 구절 전체를 처리하고, 남은 시간에는 무음을 넣는다. 음절 중간을 임의로 잘라 쉼을 삽입하지 않는다.

이 도구는 해당 샘플에 대한 검증된 편집 도구다. 다른 파일에 같은 시간값이나 tempo를 자동 적용하는 범용 자동 교정기로 사용하지 않는다. 원본 assembler와 TTS 생성 설정은 그대로 보존한다.

```bash
python repair_bora_transition.py \
  --source ORIGINAL.wav \
  --delivery delivery.json \
  --output revised-audio \
  --work edit-work
```

현재 구현은 다음 조건을 위반하면 중단한다.

1. 원본 SHA 또는 문단 시작 시점 불일치.
2. 편집 바깥 경계가 무음이 아니거나, 재배분할 여백에 유의미한 신호가 있음.
3. 실제 처리 결과가 고정 창에 들어가지 않음. 이를 맞추기 위해 발화 끝을 자르지 않음.
4. 처리한 core RMS가 0.5dB 이상 변하거나 클리핑이 있음.
5. WAV 전체 샘플 수 또는 편집창 밖 PCM이 바뀜.
6. 최종 MP3 디코딩 실패.

최종 WAV는 3,058,800 samples로 원본과 같다. 문단 강조 표시 시각도 모두 같다. MP3는 새로 인코딩하므로 창 밖 바이트 동일성 주장은 WAV에만 적용한다.

## 다음 제작 때의 검수 순서

1. 입력 원고·선택한 음성 설정·원본 음성 해시를 함께 보관한다. 자연 종료, 누락 및 반복 여부를 먼저 확인한다.
2. 문단 연결의 기존 앞뒤 여백을 포함해 실제 전환 길이를 측정한다. ‘추가 무음 0.35초’만으로 자연스러움을 판정하지 않는다.
3. 사용자 피드백 지점의 앞뒤 문장까지 확인한다. 큰 쉼 뒤 짧은 구절에 음절이 몰린 후보를 찾되, 음절 수나 에너지 임계값만으로 불량으로 확정하지 않는다.
4. ASR는 원고 누락과 구절 위치를 찾는 보조 자료다. 모델마다 단어 경계가 달라질 수 있으므로 실제 무음 확인 없이 ASR timestamp에 맞춰 자르지 않는다.
5. 원본 음색을 유지하는 작은 국소 수정부터 적용한다. 충분한 여백이 없거나 발음·억양 문제가 남으면 해당 문단만 재합성한다.
6. 원본→수정본 비교 구간과 전체 파일을 제공한다. 측정 통과와 실제 청취 판정은 구분한다.

32.20–34.01초에도 비슷한 구절 밀도 패턴이 있어 추가 청취 후보로 기록했다. 사용자가 이 구간을 문제로 지적하지 않았고, 측정만으로 불량을 확정할 수 없어 이번 수정에서는 그대로 두었다.

법령 단어에 대한 기존 ASR 불일치는 이 시간 보정으로 해결된 것이 아니다. 이 샘플을 완성 강의 전체에 대한 품질 보증으로 설명하지 않는다. 사이트/R2 배포 및 기존 음성 삭제는 이 도구가 수행하지 않는다.
