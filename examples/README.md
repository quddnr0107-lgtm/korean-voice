# 예제 — 대본과 톤 프로필

같은 안내문을 세 가지 말하기 방식으로. 톤은 `--profile 톤_*.json`, 목소리는 `--style`, 밝기·펀치는 `--bright-db`·`--punch`.

| 방식 | 대본 | 톤 | 권장 옵션 |
|---|---|---|---|
| 따뜻한 안내 | 대본_안내문_따뜻.txt | public/profiles/owner.json(본인 말투) | `--style F1:0.6,F3:0.4` |
| 짜증·강조 | 대본_안내문_짜증강조.txt | 톤_짜증강조.json | `--style M1:0.6,F4:0.4 --base-speed 1.15 --bright-db 4 --punch 0.5` |
| 일타강사 | 대본_안내문_일타강사.txt | 톤_일타강사.json | `--style M1:0.7,M3:0.3 --base-speed 1.2 --bright-db 3 --punch 0.6` |
| 시험대비강의(yebijun 일레븐랩스 남성 강의 음성의 톤: 130Hz·5.3음절/초·문장 쉼 720ms) | (원고는 yebijun exam_prep) | 톤_시험대비강의_남성.json | `--style M1:0.7,M3:0.3 --base-speed 1.05 --emotion calm` |
| 기초강의(yebijun 일레븐랩스 여성 음성의 톤: 214Hz·4.3음절/초·문장 쉼 900ms·강한 하강) | (원고는 yebijun easy_explain) | 톤_기초강의_여성.json | `--style F2:0.5,F1:0.5 --base-speed 0.95 --emotion calm --pitch-st 1.5 --bright-db -3` → 측정 225Hz·4.2음절/초 |
| 저음 내레이션(성인 남성 110~125Hz, 어두운 음색, 절제된 감정) | 대본_안내문_저음내레이션.txt | 톤_저음내레이션.json | `--style M4:0.7,M1:0.3 --base-speed 0.85 --bright-db -2 --punch 0.2` → 측정 120Hz·밝기 695Hz·4.9음절/초 |

일타강사 화법의 핵심은 대본에 있다: "자!"로 끊기, 핵심 앞 `<break time="0.4s"/>`, 되묻기("됐죠?"), 숫자 반복("다시! 육군 18…"), 짧은 문장.

## 스타일별 음높이 (pYIN 측정, 같은 문장)
F1 186 · F2 198 · F3 166 · F4 200 · F5 160 · M1 129 · M2 93 · M3 108 · M4 112 · M5 93 (Hz, 중앙값).
섞으면 대략 가중 평균 근처가 나온다(M4:0.7+M1:0.3 → 120Hz 실측). 스타일 조합만으로 100~200Hz를 덮으므로 음정 이동(`--pitch-st`)은 거의 필요 없다.

## 톤 프로필은 어떤 음성에서든 뽑을 수 있다
`python3 tools/analyze-voice.py <mp3/wav …> --out 톤.json` — 음높이·말속도·쉼·하강·문장 끝 상승을 재서 `engine` 값(쉼 4종·속도·하강폭)으로 번역한다.
음색(그 사람 목소리)은 베끼지 않는다. 남의 목소리(일레븐랩스 화자 포함)는 톤만 맞추고, 본인 목소리만 참조 음성으로 복제한다.
